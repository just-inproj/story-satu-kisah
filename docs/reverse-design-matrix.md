# Reverse Design Matrix

Prinsip: **Observe → Adopt/Adapt/Drop → Validate**. Tidak menyalin aset/copy/trademark 1:1.

## Sources (public, observed 2026-11-25)

| Source | Observasi | Adopt | Adapt | Drop |
|---|---|---|---|---|
| **Mobbin.com** | Product design reference library; positioning tajam, social proof, hero→proof→CTA, docs/MCP depth | Kejelasan value prop, proof-first, CTA tunggal, struktur informasi bersih | Terapkan ke brand WO/invitation, bukan SaaS library | UI SaaS generik, copy/asset Mobbin |
| **Apdesignku.com** | WO digital terintegrasi: undangan, guestbook, RSVP, usher, planner; WA funnel; paket 125k–399k; self-edit, garansi | Fitur inti undangan/RSVP/maps/countdown/gift, trust signal, WA CTA, mobile clarity | Naikkan kualitas editorial/premium, kurasi template, narasi lebih kuat | Kepadatan visual/template generik, klaim tanpa bukti |
| **Wedew.id** | Platform sistematis: tema, manajemen tamu, WA/email auto, RSVP, QR/check-in, guestbook, layar sapa, pricing/add-on jelas | IA fitur rapi, flow tamu terintegrasi, transparansi paket/add-on, personalisasi tamu | Untuk SSK MVP: kurasi premium + layanan WO; bukan self-serve massal kompleks | Kompleksitas dashboard besar di fase awal, gaya platform generik |

## Validation Checklist
- [ ] Tidak ada salinan aset/copy/trademark referensi.
- [ ] Keputusan desain bisa dijelaskan sebagai prinsip, bukan tiruan.
- [ ] Aksesibilitas AA, reduced-motion, mobile-first.
- [ ] Token-only styling, komponen reusable.
